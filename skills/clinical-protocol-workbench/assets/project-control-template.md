# 项目控制表

> 本文件是项目级受控工作记录，不是临床试验方案正文，也不替代原始证据或专业批准。

文件校验码由工具自动生成，用于核对文件是否变化，无须手工计算；本表采用 SHA-256 方法。校验码一致不代表临床内容已审核通过。

状态迁移规则：候选/等待证据进入 TBD 或证据台账；有精确值、适用条件及可定位确认记录的决定进入第 3 节；不采纳进入第 8 节。确认选项不等于关闭其所有证据缺口；例如样本量数值已确认而统计依据尚缺时，保留两者各自的状态。

已有经确认 Synopsis 可直接映射至第 3 节，并记录原确认出处；不必人为生成一轮新的 PROP。确认后的实质性变更需记录新的确认，旧值进入历史，按第 7 节检查全部受影响位置。
