# v0.1.0-preview.1 — 内部预览版

首次独立发行中文临床方案 Codex Skill 工作包。

- 包含撰写/审核双模式、项目控制表、设计确认与 TBD 管理、独立审核及原生审阅边界。
- 衔接口服和局部起效外用小分子皮肤科策略；固定依赖提交与 92 个受控规则文件指纹，不复制上游正文。
- 提供详细中文安装、五类使用提示、依赖排错、升级/回退/卸载说明。
- 附带受限 Word 实验模块、合成样例生成代码及 67 项回归测试；实验源码不随 Skill 自动安装。
- 发行物仅含白名单源码与合成示例，不含真实临床资料、真实项目产物或原开发 Git 历史。

这不是生产级通用 DOCX 编辑器或临床/法规批准。完整新方案 DOCX 撰写试点、Windows Word 实机、Word 缺失的完整故障演练尚未完成；复杂 OOXML 和现代批注不在实验模块支持范围。

安装时选择 tag `v0.1.0-preview.1` 下的 `skills/clinical-protocol-workbench`。压缩包校验见附件 `SHA256SUMS.txt`，源码文件校验见 `SOURCE_SHA256SUMS.txt`。详细步骤参见仓库 README。
