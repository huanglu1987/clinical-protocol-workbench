# v0.1.0-preview.3 — 医学经理公开预览版

本版完成面向临床开发部门医学经理的公开安装和详细教程，并补充直接链接安装的稳健性说明。Skill 的临床决策边界、两个策略依赖指纹和实验代码未改变。

- 仓库已公开；固定版本 Skill 链接可直接交给 Codex，并明确使用安装器的 git 方式。
- README 改为医学经理入口页，说明适用场景、两种模式、交付验收和当前边界。
- 新增《工具与工作原理》，区分内置组件、条件性专业 Skill、审核工具、医学检索实例、可选语言/召回工具、Word 能力和实验 worker。
- 新增 326 行《撰写模式详细教程》，覆盖资料准备、来源锁定、控制表、策略交接、设计确认、章节依赖、分段起草、组装、变更和交付验收，并提供逐阶段提示词。
- 新增 199 行《审核模式详细教程》，覆盖冻结目标、格式/结构检查、独立双通道、回文核实、人工处置、Word 原生修订和四层验收。
- 公开 URL 已完成匿名访问；git 方式临时全新安装得到 19 个与冻结 Skill 一致的文件。

本版仍为预览版。完整新方案 DOCX 的端到端真实项目撰写试点、Windows Word 实机和复杂 OOXML 支持仍未完成。仓库公开可见但尚未授予通用开源许可证；第三方和上游策略内容不随本仓库再分发。
