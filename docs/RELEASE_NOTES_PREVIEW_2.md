# v0.1.0-preview.2 — 医学经理公开预览版

本版主要改进公开安装与使用文档，Skill 的临床决策边界和两个策略依赖指纹未改变。

- 仓库改为公开，固定版本 Skill 链接可直接交给 Codex 安装。
- README 改为面向临床开发部门医学经理的入口页，说明适用场景、两种模式、交付验收和当前边界。
- 新增《工具与工作原理》，区分内置组件、条件性专业 Skill、审核工具、可选检索/语言工具、Word 能力和仅供开发验证的实验 worker。
- 新增《撰写模式详细教程》，覆盖资料准备、来源锁定、控制表、策略交接、设计确认、章节依赖、分段起草、组装、变更和交付验收，并提供逐阶段提示词。
- 新增《审核模式详细教程》，覆盖冻结目标、格式/结构检查、独立双通道、回文核实、人工处置、Word 原生修订和四层验收。

本版仍为预览版。完整新方案 DOCX 的端到端真实项目撰写试点、Windows Word 实机和复杂 OOXML 支持仍未完成。仓库公开可见但尚未授予通用开源许可证；第三方和上游策略内容不随本仓库再分发。
